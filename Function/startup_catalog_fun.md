# 별도 시작 창과 공용 모델 목록 · BOOT-021 · v0.2.2

사용자가 요청한 별도 흰색 시작 창과 사전 모델 준비를 반영한다. 이전의 앱 안 로딩 대화상자와 역할 설정을 열 때 원격 모델을 조회하는 동작을 대체한다.

```gherkin
Feature: 준비 후에 열리는 작업 공간
  Scenario: 첫 번째 창
    When 프로그램을 실행한다
    Then 화면 중앙에 흰색 사각형 시작 창이 먼저 나타난다
    And 메인 작업 창은 숨겨져 있다
    And 캐릭터가 돌에 걸리고 박스를 떨어뜨린 뒤 주워서 오른쪽으로 나가는 동작을 반복한다
    And 준비 단계와 완료 비율과 한국어 상태 문구를 표시한다
    And reduced-motion에서는 캐릭터 움직임을 멈춘다

  Scenario: 준비 완료
    Given 프로젝트와 설정과 연결 상태와 모델 목록을 준비했다
    When renderer 초기화와 실제 문서 로딩이 모두 끝난다
    Then 진행률을 100%로 채운 후 시작 창을 닫고 메인 창을 보여준다
    And 시작 창의 취소는 숨은 작업 창을 남기지 않고 종료한다

  Scenario: 일시적인 화면 로딩 중단
    Given 파일은 존재하지만 Electron이 ERR_FAILED 또는 ERR_ABORTED로 문서 로딩을 중단했다
    When 창이 아직 살아 있고 사용자가 앱을 종료하지 않았다
    Then 정상화한 file URL로 최대 2회 재시도한다
    And 복구된 화면이 준비된 뒤에만 메인 창을 표시한다
    And 오류 코드와 시도 횟수만 기록하고 키와 계정과 대화와 파일 경로를 기록하지 않는다
    And 반복 실패는 총 3회 후 중단하고 최종 오류를 한 번 안내한다
    And 파일 없음과 접근 차단 오류는 재시도로 숨기지 않는다
    And 복구 중 시작 창을 닫으면 추가 로딩과 오류 안내 없이 종료한다

Feature: 모델은 앱 시작 시 준비하고 화면에서는 선택
  Scenario: 공용 목록
    Given GPT와 Claude와 Cursor와 Gemini의 목록 준비를 마쳤다
    When 계정 연결 또는 역할 설정 또는 채팅창에서 모델을 고른다
    Then 준비된 같은 목록을 사용하며 목록을 다시 조회하지 않는다
    And 모델 목록 불러오기 버튼은 없다
    And 실제 로그인 또는 실행 계정을 바꾸면 이전 목록을 지우고 갱신한다

  Scenario: 실패와 격리
    Given 한 AI의 모델 조회가 실패하거나 로그인이 필요하다
    Then 해당 상태와 안내를 표시하고 나머지 준비를 마친 뒤 앱을 연다
    And 모델 조회는 공급자별 최대 60초 안에 완료 또는 실패 처리한다
    And 오래된 계정의 늦은 응답이 새 목록을 덮어쓰지 않는다
    And 목록은 현재 프로세스 메모리에만 저장하며 자격증명을 포함하지 않는다
```

검증: 단위·통합 162개, 기존 Electron 작업 공간 40개 및 별도 시작 창 6개 시나리오. 별도 검사는 모델 응답과 연결을 명시적인 테스트 값으로 격리해 창 순서, 애니메이션 단계, 100% 전환, 모델 선택 시 추가 조회 0회, 새로고침 후 현재 설정 유지, 취소 종료를 확인했다. 실제 유료 모델 추론·이미지 생성은 수행하지 않았다. 진행률은 경과 시간이나 남은 시간의 예측치가 아니다. Claude는 공식 CLI 별칭이며 로그인하지 않은 공급자의 권한을 만들어내지 않는다.
