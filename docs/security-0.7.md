# v0.7 보안 기록 · 2026-11-03

기존 [v0.6 보안 경계](security-0.6.md)를 유지하고 새 대화·테스트 기능을 검사했다.

- 대화는 프로젝트/대화 UUID로 구분하고 다른 프로젝트 문맥을 거부한다. worker 질문은 읽기 전용이며 파일 변경은 컨트롤 타워 워크플로로 조율한다.
- 앱 데이터 루트 자체를 작업 폴더로 선택하지 못한다. 상위 폴더를 선택하더라도 앱 대화·설정·인증 데이터는 스냅샷과 프로젝트 읽기/쓰기에서 제외한다. `.runtime`의 직접 상대경로 접근도 거부한다.
- 코드 실행 동의는 기본 미동의이고 기기·OS 사용자에 결합한다. renderer가 임의로 실행 옵션을 넣어 동의를 우회할 수 없다. 동의 철회 시 새 실행을 막고 실행 중 검증을 중지한다.
- 테스트 담당자는 지정된 test/tests 파일만 수정할 수 있다. 계획한 케이스가 실행되지 않거나 skip/TODO면 성공으로 판정하지 않는다. 코드 변경·취소·공급자 오류를 전체 완료로 처리하지 않는다.
- 코드 실행은 현재 OS 사용자 권한이다. 자동 의존성 설치·임의 셸 UI·컨테이너 격리는 제공하지 않는다. CLI와 테스트 코드의 악의적인 동작을 OS 수준으로 격리한다고 보장하지 않는다.
- 소스·프로필·비밀은 패키지 allowlist와 Git ignore로 분리한다. ASAR 46개 소스 일치, 인증/검사 도구 포함 0, 강화 fuse 불일치 0을 확인했다.
