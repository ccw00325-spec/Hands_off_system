# 기능 명세 버전 안내

현재 버전은 사용자 지시에 따라 다시 **0.1.0**으로 설정했다. [/fun 질문·답변·Windows 알림](fun_questions_notifications_fun.md)이 기본 켜짐인 스킬의 미정 조건 질문, 사용자 답변 후 같은 작업 재개, 시스템 알림과 체크 해제를 설명한다. /fun을 켠 상태에서는 무질문 설정으로 미정 조건을 가정하지 않는다. 끈 작업은 일반 명세로 진행하되 호스트 보호를 유지한다.

[플랫폼·설치·실행 보호](platform_safety_upgrade_fun.md)의 구조화 인계·공유 쿼터·Docker 기본 실행·텍스트 구조안·선택형 뮤테이션·설치 안내는 유지한다. 이 명세는 과거 문서의 이미지 자동 호출·뮤테이션 기본 켜짐·호스트 기본 실행 설명을 대체한다. [별도 시작 창·공용 모델 목록](startup_catalog_fun.md)의 시작 순서·목록 재사용·로딩 재시도와 [AI 설정·자동 인계](role_settings_auto_handoff_fun.md)의 역할·팀 인계, [세로 AI 데스크](agent_desk_fallback_fun.md)의 팝업·알림도 유지한다. 과거 문서는 이력으로 보존한다.

v0.7의 최신 결정·구현·검증은 [테스트·대화 작업 공간 명세](test_conversation_workbench_fun.md)와 [검증 기록](../docs/verification-0.7.md)을 기준으로 한다. 아래 항목은 v0.6까지의 변경 이력이다.

이전 명세에서 다음 항목은 변경되었다.

- 고정 3역할 → 프로젝트별 2~4패널, 복수·중복 역할과 패널 모델.
- GPT 직접 승인 중심 → 공식 Codex ChatGPT 로그인 재사용을 기본 실행 경로로 추가.
- planner 프롬프트만 Fun 전달 → 호스트의 CTR·디자인·완료 기준·작업 연결 계약 검사 추가.
- 미정이면 항상 질문 → 과거 무질문 위임 옵션을 제공했다. 현재는 /fun을 켜면 질문·명시적 답변을 우선하고, 끈 새 작업만 가역적 가정과 검토 목록을 허용한다. 치명적인 권한 누락은 어느 모드에서도 중지한다.
- 자동 수정 기본값 없음 → 초기값 2, 사용자 변경 0~20. 실제 타이머 실험은 명시적으로 6을 지정하고 3회 수정 후 통과.
- 고정 세 역할 최종 검토 → 활성화한 모든 패널이 같은 스냅샷을 읽기 전용 검토.
- 실제 추론 미검증 → GPT 전체 타이머·Claude/Grok 최소 추론 검증. Gemini 신규 Google 승인은 미검증.
- 기기와 무관한 폴더 동의 → 기기·OS 사용자 결합 검사. 기존 동의는 한 번 재연결.

검증되지 않은 항목을 과거 체크박스의 성공으로 대체하지 않는다. v0.7에서 worker별 읽기 전용 질문 채팅을 구현했다. 이미지 자동 멀티모달 전달은 미구현이다.
