원문: “첫 버전은 ‘에이전트 로그인 연결 + 이미지 생성용 개인 API 키 최초 1회 등록’을 진행하자”. 목적은 ChatGPT 로그인 권한과 독립된 개인 이미지 API 자격 증명 연결이다. 이번에는 직접 입력한 시안 설명으로 생성하며 planner 자동 생성·Claude 전달은 미구현이다.

결정 D-I01: 개인 이미지 키 최초 1회 등록 — 최신 사용자 명시 승인. D-I02: GPT Image 2 시안 생성 — 앞선 사용자 요구. D-I03: 키는 OS 보안 저장소로 보관하고 다시 불러오기 — 직전 제안에 대한 사용자 승인. 코드 관찰값인 한 장·1536×1024·medium·PNG·생성 요청 대기 제한 240초는 사용자 직접 지정값으로 기록하지 않는다.

Context: 키 없음·등록됨·교체 중·권한 부족·잔액 한도·생성 중·OS 저장소 불가. Trigger: 확인 후 저장, 저장된 키 삭제, UI 시안의 시안 생성, PNG 내보내기. 키는 password 입력이며 제출 후 화면 값을 지운다.

| 조건·입력 | 결과 |
| --- | --- |
| 빈 키·잘못된 형식 | 공급자 요청 없이 오류 표시 |

| 조회 거부 | 기존 키 유지, 공급자 원문 오류를 화면에 노출하지 않음 |
| 이미지 생성 클릭 | 개인 이미지 키로 한 번 요청, 결과 PNG를 해당 프로젝트에 저장 |
| 생성 실패 | 완료 표시 안 함, 자동 재시도 안 함 |
| 삭제 클릭 | 저장된 이미지 키 제거; OAuth 연결은 유지 |

구현 근거: `src/core/images.js`, `src/core/store.js`, `src/main.js`, `src/renderer/app.js`. 검증: `test/images.test.js`의 조회·교체 실패·OAuth 토큰 분리·무재시도, `scripts/smoke.mjs`의 invalid 입력 제거와 Windows 실제 암호화 검사 통과. v0.2는 동의받은 프로젝트 폴더의 design/에 PNG를 저장하며 테스트 이미지로 실제 저장·재실행 복원을 확인했다. 실제 유료 생성·PNG 내보내기는 실계정 미실행이다.

한계·리스크: 모델 조회는 잔액 및 이미지 생성 권한을 보증하지 않는다. 네트워크가 끊겨도 공급자에서 이미 처리했을 수 있어 재시도 전 사용 내역 확인이 필요하다. 생성 이미지와 프로젝트 메타데이터는 로컬 파일이며 비밀 키와 달리 암호화 대상이 아니다. 사용자별 API 비용·로그인 지원 조건은 공급자에 따른다. 현재 기술 구현값의 제품 옵션화는 후속 결정이다. 관련 기능은 `agent_login_fun.md`. 조사 범위는 위 파일과 OpenAI 공식 이미지·인증 문서. 인증정보 실값은 문서에 포함하지 않았다.
