## 자동 검사 범위

데스크톱 검사는 공급자 응답을 명시적 fixture로 대체한다. 실제 coordinator, IPC, 저장소, Node 테스트 프로세스와 Electron DOM을 검사한다. 유료 추론 호출은 0회다.

- 새 프로젝트의 즉시 네이티브 폴더 선택, 취소 시 빈 프로젝트 미생성, 동의 후 생성.
- 폴더 아래 대화 생성·검색·전환·전체 앱 재시작 복원, 대화별 작업과 패널별 응답 분리.
- 작업자 위·대형 컨트롤 타워 아래 배치, 중앙 폴더/FILES/권한 컨트롤 제거와 설정 이전.
- 하나의 GPT 계정으로 2~4패널, 복수 역할·테스트 역할·모델 선택.
- 테스트 계획/코드/재현 절차, 실제 TAP 출력, 의도적으로 잘못된 구현 → 담당자 수정 → UI/테스트 재실행 → 완료.
- 테스트 담당자의 앱 코드 수정 거부, 여러 테스트 담당자의 파일 중복 배분 거부, skip/누락 케이스가 있으면 성공 거부.
- 검증 중 소스 변경의 이전 결과 무효화, 공급자 중단 시 영구 진행 표시 방지.
- 최초 실행 권한 기본 미동의, 다른 기기·OS 사용자에 동의 미복사, 앱 대화·인증 데이터의 프로젝트 접근/스냅샷 제외.
- 각 worker의 질문과 컨트롤 타워 질문 중지, 완료 작업의 문맥 보존.
- 실제 작업 전달 이벤트에 따른 상자 이동, 움직임 끄기, 5시간/주간 한도 각각 표시.
- 1920/1440/900/768/414/375/320px 가로 넘침 없음.

## 실제 AI 검사와 제한

공식 Codex ChatGPT 기존 인증과 실제 카탈로그 모델을 사용했다. 독립 질문 실험은 `gpt-5.6-luna`, 두 패널·4개 메시지·2개 응답을 확인했고 파일 수정과 코드 실행 동의 없이 읽기 전용으로 종료했다.

타이머 실험에는 Fun을 첫 계획자에게만 제공하고 테스트 역할을 추가했다. 첫 `gpt-5.6-sol` 실험에서는 생성 테스트 13개와 호스트 검사를 통과한 뒤 경계 조건 보완 중 공급자 오류로 중단됐다. 후속 `gpt-5.6-luna` 실험에서는 자동 수정 후 생성 테스트 **9개**, 해시 고정된 `checks.cjs`, 실제 Electron의 시작/진행/일시정지/재개/완료/초기화/잘못된 입력 검사를 통과했다.

그러나 최종 AI 검토가 브라우저 갱신 검증 범위·증빙에 대한 지적을 남겼고 자동 수정 한도에 도달했다. 따라서 최종 상태는 **needs_attention**, 전체 성공은 **false**다. 테스트 실행 성공을 전체 검토 완료로 바꾸지 않았다. 두 실험 모두 생성한 타이머 폴더는 소유 표시와 실경로 경계를 확인한 뒤 삭제했다. `artifacts/timer-qa-report.json`과 타임스탬프 보고서에 결과를 보존한다.

검사 도구의 실행 증빙이 요약 문자열에만 있고 출력에는 QA TAP만 남는 불편도 확인했다. 이후 재현 스크립트는 호스트 코어 stdout과 Electron assertion 결과를 QA 출력과 함께 집계하도록 보완했다. 이 변경 후 추가 유료 전체 실험은 반복하지 않았으므로 새 로그 집계가 최종 AI 지적을 모두 해소했다고 주장하지 않는다.

이전 버전의 실제 Claude/Cursor 최소 추론·Gemini 메타데이터 확인은 [v0.6 기록](verification-0.6.md)에 보존한다. 이번 버전에서 모든 공급자의 전체 생성 파이프라인을 재실행한 것은 아니다. Google 신규 승인·유료 이미지 생성·다른 PC의 최초 설치는 미검증이다.
