## 언제 바로 사용할 수 있나요?

개인 학습·평가·비상업적 연구 목적으로 수정하지 않은 앱을 실행할 수 있습니다. 소스를 그대로 빌드하고 계정을 연결하거나 앱의 설정을 바꾸는 것도 가능합니다. 자신의 프로젝트 폴더에 앱이 생성한 파일을 편집하는 것은 Hands off 자체의 코드를 수정하는 것과 다릅니다.

비상업적 목적으로 원본을 그대로 나눠줄 때는 LICENSE·NOTICE와 제삼자 고지를 함께 보존하세요. 저작권자 이름과 아이디를 지웠거나 출처만 적은 채 별도 승인이 필요한 용도로 사용하는 것은 허용하지 않습니다.

## 어떤 경우에 승인을 받아야 하나요?

| 하려는 일 | 사전 서면 승인 |
| --- | --- |
| 개인·학습용으로 수정하지 않은 앱 실행, 설정 변경, 원본 빌드 | 불필요 |
| 원본 소스·내장 스킬·프롬프트·프로젝트 고유 자산을 수정하거나 파생 개발 | 필요 |
| 회사의 상업적 업무, 유료 고객 작업, 판매·구독·광고·SaaS·상용 제품에 이용 | 필요 |
| 수익화를 위한 이용을 시작하되 아직 매출은 없는 경우 | 필요 |
| 프로젝트의 코드·스킬·프롬프트·문서 등을 모델 학습·파인튜닝·증류에 사용 | 비상업적 학습도 필요 |
| 허용된 용도로 앱을 쓰면서 AI에 일반적인 추론을 요청 | 학습·파인튜닝 자체로 보지 않음 |

사용자 입력과 독립적인 생성물의 저작권을 단지 이 앱을 이용했다는 이유로 가져오지 않습니다. 다만 앱 자체를 유료 고객 작업 등 상업적 목적으로 운영하는 행위에는 승인이 필요하며, Hands off 원본 코드를 복사한 부분의 조건은 유지됩니다. 아이디어·알고리즘 자체와 제삼자 자료에 대한 권리를 주장하는 조건이 아닙니다.

## 공개 코드와 수정 권한

이 프로젝트는 Apache-2.0이 아닌 전용 소스 공개 라이선스를 사용합니다. Apache-2.0은 상업적 이용과 수정을 허용하므로 위 사전 승인 조건과 함께 동일한 라이선스라고 표시할 수 없습니다. [Apache 공식 설명](https://www.apache.org/foundation/license-faq)

공개 GitHub 저장소는 GitHub 약관에 따른 열람·포크가 가능합니다. 외부인의 컴퓨터에 받은 파일을 기술적으로 잠그거나 이미 받은 복사본을 회수하지는 못합니다. 정식 저장소의 쓰기 권한과 외부 복사본은 구분됩니다. [GitHub 라이선스 안내](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)

CODEOWNERS는 검토 담당자를 표시하는 파일입니다. 그 파일만으로 병합 제한이 강제되는 것은 아닙니다. 정식 저장소에 직접 반영하는 권한은 저장소 접근 권한으로 관리합니다.

앱에 수익화 감시·라이선스 추적·자동 신고 이메일 전송 기능을 추가하지 않았습니다. 사용자의 파일·키·활동을 저작권자에게 전송하지 않으며, 다른 사람이 상업적으로 쓰는지 자동으로 발견한다고 보장하지 않습니다.

Lobe Icons, Electron, jose 등 제삼자 구성 요소의 권리는 각각의 라이선스를 따릅니다. 이 전용 조건은 그 권한을 제한하지 않습니다. 실제 분쟁 대응과 조건의 집행 가능성은 사용 지역과 구체적인 사안에 따라 별도 법률 검토가 필요합니다.
