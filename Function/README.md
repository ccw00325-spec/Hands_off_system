# 기능 명세 버전 안내

v0.6의 최신 결정·구현·검증은 [유연한 작업 공간 명세](flexible_workbench_fun.md)와 [검증 기록](../docs/verification-0.6.md)을 기준으로 한다. 다른 파일은 초기 버전의 결정과 검증 이력을 보존한다.

이전 명세에서 다음 항목은 변경되었다.

- 고정 3역할 → 프로젝트별 2~4패널, 복수·중복 역할과 패널 모델.
- GPT 직접 승인 중심 → 공식 Codex ChatGPT 로그인 재사용을 기본 실행 경로로 추가.
- planner 프롬프트만 Fun 전달 → 호스트의 CTR·디자인·완료 기준·작업 연결 계약 검사 추가.
- 미정이면 항상 질문 → 무질문 위임 옵션에서 가역적 가정과 검토 목록 기록. 치명적인 권한 누락은 중지.
- 자동 수정 기본값 없음 → 초기값 2, 사용자 변경 0~20. 실제 타이머 실험은 명시적으로 6을 지정하고 3회 수정 후 통과.
- 고정 세 역할 최종 검토 → 활성화한 모든 패널이 같은 스냅샷을 읽기 전용 검토.
- 실제 추론 미검증 → GPT 전체 타이머·Claude/Grok 최소 추론 검증. Gemini 신규 Google 승인은 미검증.
- 기기와 무관한 폴더 동의 → 기기·OS 사용자 결합 검사. 기존 동의는 한 번 재연결.

검증되지 않은 항목을 과거 체크박스의 성공으로 대체하지 않는다. 이미지 자동 멀티모달 전달과 worker별 독립 채팅은 여전히 미구현이다.
